## 1. Câu hỏi của user đã được trả lời (SSRF không cần outbound)

## 4. Prototype pollution — vector MỚI xác nhận (differential sạch)

Lưu ý quan trọng: `Object.prototype` là **global mọi session** — các lần test trước lẫn trạng thái. Phải clean (`ogImage: null`) trước mỗi test:

| Vector | Kết quả trên nền sạch |
|---|---|
| `{"constructor":{"prototype":{...}}}` top-level | ✅ EAT (đã biết từ 3.md) |
| `{"links":{"constructor":{"prototype":{...}}}}` | ✅ **EAT — MỚI** |
| `{"links":[{"constructor":{"prototype":{...}}}]}` (phần tử array!) | ✅ **EAT — MỚI** |
| `{"accent":{"constructor":...}}` | ❌ DEAD |
| `{"constructor":{"prototype":{"__proto__":...}}}` 2 tầng | ❌ DEAD |
| `{"ogImage": ...}` trực tiếp | ❌ bị strip đúng schema (PUT 200 nhưng profile không có, fetch không đổi) |

Cleanup: put `ogImage: null` (hoặc `""`) qua `constructor.prototype` → preview quay lại "no og:image". `false`/`0` thành giá trị fetch → lỗi "refused to fetch false".
